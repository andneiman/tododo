# Tods

Быстрый офлайн to-do в духе Microsoft To Do: iOS-приложение на SwiftUI, синхронизация через маленький бэкенд на Vercel и управление из Claude через MCP.

- `Tods/`, `Tods.xcodeproj` — приложение (iOS 17+). Все данные в памяти и в одном JSON-файле на устройстве, сеть нужна только для синка.
- `backend/` — Vercel Functions: `POST /api/sync` (приложение) и `/api/mcp/<token>` (коннектор Claude). Состояние — один приватный Vercel Blob.

## Как устроено

- Всё — записи одного вида (`group`, `list`, `task`, `step`). У каждого поля записи своя метка времени, сервер сливает правки по полям: переименовал на телефоне, отметил звёздочкой на Маке — сохранится и то и другое.
- Приложение всегда работает с локальной копией. Изменения копятся в очереди и уходят при первой возможности: сразу после правки, при возврате сети, при открытии приложения; пока сервер недоступен — повторы с растущей паузой.
- «Мой день» не обнуляется: задача остаётся там, пока её не завершат или не уберут.
- Отбивка — задача с `isSection`; создаётся, если название начинается с `#`.

## Сохранность данных

- Сервер ничего не стирает: удалённое помечается и восстанавливается (инструмент `recover` в коннекторе Claude).
- Раз в день (при первом изменении) сервер сохраняет полный снимок в Postgres и копию в Vercel Blob, хранит 90 дней.
- Каждое устройство раз в день сохраняет копию своего файла (30 дней) и поднимается из неё, если основной файл повреждён.
- Если сервер потеряет данные, любое устройство зальёт их обратно при следующей синхронизации.

## Тесты

- `scripts/e2e.sh` — два настоящих процесса приложения («телефон» и «Мак») против локального сервера: офлайн, слияние правок, удаление против правки, потеря данных сервера, повреждение локального файла.
- `backend/test/sync.test.mjs` — серверная логика на Postgres.
- Оба запускаются в GitHub Actions при каждом пуше вместе со сборкой iOS и macOS и скриншотами всех экранов (ветки `ci-shots`, `ci-mac`).

## Подключение приложения

Откройте на устройстве ссылку вида `tods://setup?url=<адрес сервера>&token=<токен>` или вставьте её в Настройки → Подключение.

## TestFlight

`.github/workflows/testflight.yml` — ручной запуск; нужны секреты `ASC_ISSUER_ID`, `ASC_KEY_ID`, `ASC_KEY_P8`, `APPLE_TEAM_ID`.
