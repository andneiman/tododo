# Tododo

Быстрый офлайн to-do в духе Microsoft To Do: iOS-приложение на SwiftUI, синхронизация через маленький бэкенд на Vercel и управление из Claude через MCP.

- `Tododo/`, `Tododo.xcodeproj` — приложение (iOS 17+). Все данные в памяти и в одном JSON-файле на устройстве, сеть нужна только для синка.
- `backend/` — Vercel Functions: `POST /api/sync` (приложение) и `/api/mcp/<token>` (коннектор Claude). Состояние — один приватный Vercel Blob.

## Как устроено

- Всё — записи одного вида (`group`, `list`, `task`, `step`) с `updatedAt`; конфликт решается «последняя запись побеждает».
- «Мой день» не обнуляется: задача остаётся там, пока её не завершат или не уберут.
- Отбивка — задача с `isSection`; создаётся, если название начинается с `#`.

## Настройка приложения

Адрес сервера и токен задаются в приложении (шестерёнка → Сервер) или в файле `Tododo/Secrets.plist` (в git не попадает) с ключами `ServerURL` и `AppToken`.
